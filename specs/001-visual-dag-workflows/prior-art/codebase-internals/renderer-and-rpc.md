# Plan research: renderer + RPC (part 1)

Headline facts:
- Orchestration pushes nothing to the renderer: no `orchestration:*` IPC event/stream. Renderer only gets agent labels (task, dispatch, run id) via window-graph sync. A live run view needs a new host-side stream.
- `files.read` returns preview-sized content with a `truncated` flag; renderer refuses to open truncated files for editing.
- No graph/canvas lib installed; precedent exists for importing a library's own stylesheet from a component.
- `docs/STYLEGUIDE.md` has no "Enforcement" section; lint rules only in `config/oxlint-design-system.json`.

## B6 Registering a method family
- `src/main/runtime/rpc/core.ts` `defineMethod({name, params, handler(params, ctx)})`, `defineStreamingMethod({name, params, handler(params, ctx, emit)})`. RpcContext: runtime, connectionId, signal, requestId, clientKind?, clientCapabilities, updateClientCapabilities.
- Streaming lifecycle (`methods/notifications.ts:17-47`, `client-events.ts`): subscribe emitter -> `runtime.registerSubscriptionCleanup(subscriptionId, cleanup, connectionId)` -> `emit({type:'ready', subscriptionId})` -> keep promise pending -> companion `*.unsubscribe` calls `runtime.cleanupSubscriptionAndWait(id)`. id `${family}-${connectionId ?? 'inproc'}-${++seq}`.
- Family files `methods/<family>.ts` export `X_METHODS = [defineMethod(...)]`; subfolders for large families. Registry `methods/index.ts` `ALL_RPC_METHODS` flat manifest. `buildRegistry`, `eraseRpcMethods` in core.ts; dispatcher `rpc/dispatcher.ts`.
- Params: `src/shared/rpc-contract/<family>-params.ts` zod; new style `z.object({...}).strict()`; primitives in `rpc-param-primitives.ts`; unknown keys stripped by default.
- Catalog: `generate:rpc-params-catalog` bundles methods/index.ts + shared contracts, matches schema identity to exported names, writes `rpc-params-catalog.generated.ts`; `verify:` in lint. Each params schema must be exported from src/shared and bound by identity. `RPC_METHODS_WITHOUT_SHARED_PARAMS` exists for schemas reaching into src/main.
